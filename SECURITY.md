# Security policy

## Reporting a vulnerability

Report it privately through GitHub's
[private vulnerability reporting](https://github.com/Haembina/sonarqube-branch-analysis/security/advisories/new),
not in a public issue. Say which release you ran, what an attacker can reach, and how to reproduce it.

A confirmed vulnerability is fixed in a release, and its advisory is published with that release.

## Supported versions

Only the newest release gets fixes.
